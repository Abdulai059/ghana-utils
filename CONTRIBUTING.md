# Contributing

Thanks for helping! Bug reports, wrong prefixes and new helper ideas are all welcome.

## Setup

```bash
git clone https://github.com/YOUR_USERNAME/ghana-utils.git
cd ghana-utils
npm install
npm test
```

## Pull requests

1. Open an issue first for big changes.
2. Add tests for every change.
3. Make sure `npm test` and `npm run build` pass.
4. Add a line to the `[Unreleased]` section of CHANGELOG.md.
5. Keep the package zero-dependency.
